- LFUSE = 0x62

Decoded from ATmega328PB datasheet DS40001906C. These match the shipping defaults.
- LFUSE 0x62: CKSEL=0010 calibrated internal RC oscillator, nominal 8.0 MHz. SUT=10, slow-rising-power start-up (6 CK + 19 CK + 65 ms). CKOUT unprogrammed, so no clock on PB0. CKDIV8 programmed, so the prescaler starts at divide-by-8.
- CPU clock = 1.0 MHz. Matching compiler assumption: F_CPU=1000000UL.
- HFUSE 0xD9: RESET remains RESET (RSTDISBL unprogrammed). debugWIRE disabled (DWEN unprogrammed). ISP enabled (SPIEN programmed). Watchdog not forced on (WDTON unprogrammed). EEPROM not kept through chip erase (EESAVE unprogrammed). BOOTSZ=00, maximum boot size. BOOTRST unprogrammed, so reset starts the application at address 0.
- EFUSE 0xF7: CFD programmed, which disables clock-failure detection. BODLEVEL=111, brown-out detector disabled. Upper bits are the unused defaults.
